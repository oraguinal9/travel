第一章 · 全等三角形

形状大小相同对应边相等对应角相等SSS/SAS/ASA/AASHL(直角)

一、图形的全等

  • 两个图形形状相同、大小相等，把其中一个图形经过平移、旋转、翻折后能与另一个完全重合，就说这两个图形全等。
  • 全等图形的形状和大小完全相同（只是位置可能不同）。

二、全等三角形

  • 定义：能完全重合的两个三角形叫全等三角形。
  • 记法：△ABC ≌ △A′B′C′，"≌"读"全等于"。顶点顺序对应：A↔A′、B↔B′、C↔C′。
  • 性质：全等三角形的对应边相等、对应角相等（由此推得周长、面积、对应高/中线/角平分线都相等）。
  • 找对应边/角的方法：① 公共边、公共角是对应边/角；② 最长边对最长边、最大角对最大角；③ 对应顶点所对边是对应边。

三、三角形全等的判定

简写名称条件（已知）注意
SSS边边边三边对应相等最基本
SAS边角边两边及其夹角相等必须是夹角！
ASA角边角两角及其夹边相等夹边
AAS角角边两角及一角的对边相等非夹边也行
HL斜边直角边直角△：斜边+一条直角边相等仅用于直角三角形
  • 不能判定全等：AAA（三角相等只能相似）、SSA（两边及非夹角，一般不行）。

四、角平分线的性质

  • 角平分线上的点到角两边的距离相等。
  • 到角两边距离相等的点，在这个角的平分线上。
⚠️ 易错： ① SAS 的"角"必须是两边的夹角，写成 SSA 不能判全等； ② 写"≌"时字母要对应写，△ABC≌△DEF 表示 A 对 D； ③ 公共边、对顶角本身就是对应边、对应角，常用来凑条件； ④ 证明题要"三步走"：① 找已知相等的边/角；② 选判定方法；③ 写结论。
典型例题
1. 如图，AB=AC，AD 平分∠BAC，则 △ABD ≌ △ACD（SAS：AB=AC，∠BAD=∠CAD，AD=AD）。
2. 已知 ∠A=∠D，∠B=∠E，BC=EF，则 △ABC ≌ △DEF（AAS）。
3. 直角三角形两直角边 6、8，则斜边 10；用 HL 可证与另一斜边长 10、直边长 6 的直角△全等。
看解题要点
先用已知（公共边/对顶角/平行得角等）凑齐判定所需条件；判定只认 SSS/SAS/ASA/AAS/HL 五种。

第二章 · 轴对称图形

对称轴对称点连线被垂直平分中垂线角平分线等腰 三线合一

一、轴对称与轴对称图形

  • 轴对称：两个图形沿一条直线对折后能完全重合，叫轴对称，这条直线是对称轴。
  • 轴对称图形：一个图形沿一条直线对折，直线两旁的部分能完全重合，这个图形就是轴对称图形（如等腰三角形、正方形、圆）。
  • 性质：① 对称点的连线被对称轴垂直平分；② 对应线段相等、对应角相等。

二、线段、角的轴对称性

  • 线段是轴对称图形，有 2 条对称轴：线段所在直线、线段的垂直平分线（中垂线）。中垂线上的点到线段两端距离相等。
  • 角是轴对称图形，对称轴是角平分线。角平分线上的点到角两边距离相等。

三、等腰三角形

  • 定义：有两边相等的三角形（相等的两边叫腰，另一边叫底边）。
  • 性质：① 两腰相等；② 两底角相等（等边对等角）；③ 三线合一：顶角的平分线、底边上的中线、底边上的高互相重合。
  • 判定：有两角相等的三角形是等腰三角形（等角对等边）。

四、等边三角形

  • 三边都相等；三个内角都是 60°。
  • 具有等腰三角形的一切性质；三条对称轴（每条边上的高/中线/角平分线所在直线）。

五、直角三角形性质

  • 斜边上的中线等于斜边的一半。
  • 在直角三角形中，如果一个锐角等于 30°，那么它所对的直角边等于斜边的一半。
⚠️ 易错： ① "三线合一"只适用于等腰三角形（含等边），且只对顶角、底边那一处成立； ② 轴对称图形是一个图形，轴对称是两个图形的关系； ③ 角的对称轴是直线（角平分线所在直线），不是射线； ④ 等腰三角形"等边对等角"要找准底角（两底角相等，不是与顶角等）。
典型例题
1. 等腰三角形顶角 80°，则底角 = (180°−80°)÷2 = 50°。
2. 等腰三角形一边长 5、一边长 8，则周长 = 18 或 21（腰 5 底 8 或腰 8 底 5，均满足三边关系）。
3. 直角三角形斜边 10，斜边上中线 = 5。
看解题要点
等腰"分类讨论"：没说哪条是腰，要分两种情况并检验是否构成三角形；顶角+2×底角=180°。

第三章 · 勾股定理

a²+b²=c²勾三股四弦五面积法证明逆定理 直角三角形勾股数

一、直角三角形三边关系

  • 直角三角形两直角边的平方和，等于斜边的平方：a² + b² = c²（c 为斜边）。
  • 文字：勾² + 股² = 弦²。"勾三股四弦五"是最有名的一组（3²+4²=5²）。

二、勾股定理（证明：面积法）

  • 赵爽弦图：四个全等的直角三角形围成大正方形，中间留一个小正方形，面积关系推出 a²+b²=c²。
  • 常用证法还有"毕达哥拉斯拼图"（两个大正方形拼法不同、面积相等）。

三、勾股定理的逆定理

  • 如果三角形三边满足 a² + b² = c²，那么这个三角形是直角三角形（c 所对角是直角）。
  • 常用于"已知三边判断是不是直角三角形"。
  • 勾股数：满足 a²+b²=c² 的正整数组，如 (3,4,5)、(5,12,13)、(8,15,17)、(7,24,25)。

四、实际应用

  • 求最短路径（展开立体图形再连线）、求旗杆/河宽高度、判断直角。
  • 例：梯子长 2.5m 靠墙，底端离墙 1.5m，则墙上高度 = √(2.5²−1.5²) = 2 m。
⚠️ 易错： ① 必须在直角三角形中才用 a²+b²=c²，c 永远是斜边； ② 计算时别漏平方：a²+b²=c²，不是 a+b=c； ③ 逆定理用来"判定直角"，原定理用来"求边长"，方向相反； ④ 最短路径题要先展开再求两点直线距离。
典型例题
1. 直角△两直角边 6、8，斜边 = √(6²+8²)=√100 = 10。
2. 三边 5、12、13：5²+12²=169=13² → 是直角三角形。
3. 圆柱高 12、底面周长 16，侧面上 A 到 B(顶端对面) 最短 = √(12²+8²)=√208≈14.4（半个周长=8）。
看解题要点
套公式前先确认直角与斜边；逆定理用"最长边的平方 是否等于 另两边平方和"判定。

第四章 · 实数

平方根 √算术平方根立方根 ³√有理数+无理数数轴表示

一、平方根

  • 若 x² = a（a≥0），则 x 叫 a 的平方根，记作 ±√a。
  • 算术平方根：正的平方根，记作 √a（a≥0，√a≥0）。0 的算术平方根是 0；负数没有平方根。
  • 性质：(√a)² = a；√(a²) = |a|。

二、立方根

  • 若 x³ = a，则 x 叫 a 的立方根，记作 ³√a。
  • 任何实数都有唯一立方根；立方根符号与被开方数相同（正数正、负数负、0 为 0）。

三、实数

  • 无理数：无限不循环小数（如 √2、π、0.1010010001…）。
  • 实数 = 有理数（整数、分数、有限小数、循环小数）+ 无理数。实数与数轴上的点一一对应。
  • 实数的相反数、绝对值、运算与有理数相同：|a| 当 a≥0 为 a，a<0 为 −a。

四、近似数

  • 四舍五入；精确到某位 / 保留 n 位小数 / 保留 n 位有效数字。
  • 例：√2 ≈ 1.414（精确到千分位）；π ≈ 3.14。
⚠️ 易错： ① 负数没有平方根，但有立方根（如 ³√(−8)=−2）； ② √a² = |a|，不是 a（当 a 为负时要变号）； ③ 带根号的数不一定是无理数：√4=2 是有理数、³√(−8)=−2 是有理数； ④ 无理数不能写成两个整数之比（分数），√2 不是 1.414 那样的有尽小数。
典型例题
1. 16 的平方根是 ±4，算术平方根是 4（注意区分"平方根"和"算术平方根"）。
2. ³√(−27) = −3；√9 = 3（√9 指算术平方根）。
3. 下列各数中是无理数的是 √2、π；√4、0.3̅ 是有理数。
看解题要点
先判断符号与是否开方尽；"平方根"有两值，"算术平方根"只取非负那一个。

第五章 · 平面直角坐标系

x轴 y轴 原点四个象限坐标 (x,y)对称变换平移

一、平面直角坐标系

  • 两条互相垂直的数轴：水平 x 轴（横轴，向右正），竖直 y 轴（纵轴，向上正），交点叫原点 O。
  • 平面内一点 P 用有序数对 (x, y) 表示，x 是横坐标、y 是纵坐标。
  • 象限：去掉坐标轴分四块，逆时针为一、二、三、四象限；坐标轴上的点不属于任何象限。

二、坐标的符号规律

位置第一象限第二第三第四x轴y轴
坐标(+,+)(−,+)(−,−)(+,−)(x,0)(0,y)
  • 点到 x 轴距离 = |y|，到 y 轴距离 = |x|。

三、图形与坐标变换

  • 关于 x 轴对称：(x,y) → (x,−y)（横不变、纵变号）。
  • 关于 y 轴对称：(x,y) → (−x,y)（纵不变、横变号）。
  • 关于原点对称：(x,y) → (−x,−y)（都变号）。
  • 平移：向右 a：(x+a,y)；向上 b：(x,y+b)。
⚠️ 易错： ① 坐标有顺序：(2,3) ≠ (3,2)； ② 坐标轴上的点不在任何象限（如 (5,0)、(0,−3)）； ③ 关于 x 轴"横不变纵变号"，别记反； ④ "距离"是绝对值：到 x 轴距离=|y|，不是 y。
典型例题
1. 点 P(3,−2) 在第 四 象限；到 x 轴距离 2，到 y 轴距离 3。
2. 点 A(2,5) 关于 y 轴对称点是 (−2,5)；关于原点对称是 (−2,−5)。
3. 点 (1,2) 先右移 3、再上移 1 → (4,3)。
看解题要点
判断象限看 (x,y) 正负号；对称变换记住"关于谁，谁不变"。

第六章 · 一次函数

常量 变量函数 y随xy=kx+bk定增减b定截距

一、函数

  • 常量：过程中不变的量；变量：变化的量（x 自变量、y 因变量）。
  • 函数：在某变化过程中，有两个变量 x、y，若 x 每取一个值，y 都有唯一确定的值与它对应，则 y 是 x 的函数。
  • 函数三种表示：解析式、表格、图像。

二、一次函数

  • 一般形式 y = kx + b（k、b 为常数，k ≠ 0）。
  • 当 b = 0 时，y = kx 叫正比例函数（特殊的一次函数）。

三、一次函数的图像与性质

  • 图像是一条直线；两点法画图（通常取与两轴交点）。
  • k 决定增减性：k>0，y 随 x 增大而增大（上升）；k<0，y 随 x 增大而减小（下降）。
  • b 决定与 y 轴交点：(0, b)。与 x 轴交点：(−b/k, 0)。

四、待定系数法

  • 已知图像过两点，设 y=kx+b，代入坐标列方程组，解出 k、b 得解析式。
  • 一次函数与方程、不等式：y=kx+b 中 y=0 即对应方程；y>0 即对应不等式解集。
⚠️ 易错： ① 一次函数要求 k ≠ 0；b 可以为 0（此时是正比例）； ② k 的正负决定增减，不是 b； ③ "y 随 x 增大而增大" ⇔ k>0； ④ 图像与 y 轴交点只看 b，与 x 轴交点是令 y=0 求得。
典型例题
1. y=(m−2)x+3 是一次函数 ⇒ m≠2；是正比例 ⇒ m≠2 且 3=0（不可能，故不能是正比例）。
2. y=−2x+4：k<0 故 y 随 x 增大而减小；与 y 轴交于 (0,4)，与 x 轴交于 (2,0)。
3. 过 (0,1)、(2,5) 的一次函数：设 y=kx+b ⇒ b=1, 2k+1=5 ⇒ k=2 ⇒ y=2x+1。
看解题要点
待定系数法代入两点列方程；图像走势看 k 正负，截距看 b。

第七章 · 数据的收集、整理、描述

普查 抽样总体 样本频数 频率直方图条形/折线/扇形

一、调查方式

  • 普查：考察全体对象（如人口普查）。优点准确，缺点是工作量大、有时有破坏性。
  • 抽样调查：从总体中抽取样本考察。相关概念：总体（全体）、个体（每个对象）、样本（抽出部分）、样本容量（样本中个体数目，无单位）。
  • 抽样要具有代表性和广泛性。

二、频数分布

  • 频数：某个数据出现的次数；频率 = 频数 ÷ 总数（频率之和=1）。
  • 组距与组数：把数据分段，每段叫一组。画频数分布直方图：横轴是分组、纵轴是频数，矩形宽=组距、高=频数，各矩形相连无空隙。

三、数据的表示

统计图特点 / 用途
条形图直观比较各项目数量多少
折线图显示数据变化趋势（增减）
扇形图显示各部分占总体百分比
直方图显示数据在各区间的分布（频数）

四、集中趋势

  • 平均数：总和÷个数；中位数：排序后中间位置的数；众数：出现次数最多的数。
⚠️ 易错： ① 样本容量是个数，不带单位； ② 直方图矩形相连（无空隙），条形图矩形分开； ③ 扇形图用百分比，各扇形圆心角=360°×百分比； ④ 平均数受极端值影响大，中位数不受。
典型例题
1. 了解全班视力，适合普查；了解全市中学生视力，适合抽样调查。
2. 数据 1,2,2,3,4：平均数=2.4，中位数=2，众数=2。
3. 频率=频数÷样本容量；某组频数 8、总数 40，则频率=0.2。
看解题要点
先判断调查方式；直方图与条形图别混；扇形看百分比。
